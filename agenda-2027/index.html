About your PDF

The new Download PDF action creates an A4, multi-page document directly—no Print menu needed. It includes your saved entries for the selected period. Share PDF opens the system share sheet when your browser supports file sharing. This is a personal export, not an Amazon KDP-ready book interior.

PDF text currently uses standard built-in fonts; some emoji and non-Latin characters may appear as question marks. Keep the JSON backup as your complete editable archive.

Daily verse texts use short passages from the public-domain King James Version, selected from a curated rotating set. This agenda rotates a curated set of Scripture excerpts; it does not include a unique verse every day.
